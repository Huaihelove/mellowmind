# Local Resources

- `Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`: single 1024 × 1024 app icon generated by `Tools/generate_assets.mjs`.
- `Assets.xcassets/AccentColor.colorset`: Morandi-inspired soft lilac accent color with light and dark variants.
- `Assets.xcassets/LaunchBackground.colorset`: launch background with light and dark variants.
- `Audio/cloud_rain.wav`: 16-second looping cloud rain.
- `Audio/moon_breath.wav`: 20-second looping breathing soundscape.
- `Audio/quiet_stream.wav`: 18-second looping quiet stream.
- `Audio/soft_hearth.wav`: 18-second looping hearth sound.

All audio and icon assets are synthesized by project scripts and contain no third-party copyrighted material. To regenerate:

```bash
node Tools/generate_assets.mjs
```
